## 🔍 BUSCAR DENTRO DEL MANUAL

Para buscar un tema específico:

1. En Word abierto: Presiona Ctrl+F
2. Escribe la palabra que buscas
3. Word resaltará todas las coincidencias
4. Navega con flechas arriba/abajo

Ejemplos:
- "Medicamento controlado" → Te lleva a esa sección
- "Receta" → Encuentra todas las referencias
- "Precio" → Muestra dónde editar precios
- "Error" → Busca soluciones

## 🔧 PERSONALIZAR MANUALES

¿Necesitas cambiar información de contacto?

1. Abre archivo .docx con Word
2. Presiona Ctrl+H (Reemplazar)
3. Busca: "XXXX XXXX"
4. Reemplaza con: Tus números reales
5. Guarda cambios

O regenera con scripts (más profesional):
1. Edita: generar_manual_completo.py
2. Busca números de teléfono y email
3. Ejecuta: python generar_manual_completo.py

## 📸 AGREGAR SCREENSHOTS

Para agregar capturas de pantalla reales:

1. Toma screenshots del sistema
2. Guarda en carpeta: screenshots/
3. En scripts Python, agrega:
   add_screenshot(doc, "screenshots/01_login.jpg")
4. Regenera: python generar_manual_*.py
